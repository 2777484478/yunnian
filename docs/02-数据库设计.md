# YunNian 云辇 · 核心数据表设计（MySQL 8.0）

> 字符集统一 `utf8mb4 / utf8mb4_0900_ai_ci`；引擎 `InnoDB`；
> 所有表带 `created_at / updated_at / created_by / updated_by`（除纯流水表外）；
> 金额/时间用 `DECIMAL` / `DATETIME(3)`，禁止用字符串存时间。

## 1. 用户 / 角色 / 权限

```sql
-- ---------------------------------------------------------------------------
-- 1.1 用户
-- ---------------------------------------------------------------------------
CREATE TABLE `user` (
  `id`            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键',
  `username`      VARCHAR(64)     NOT NULL                COMMENT '登录账号，唯一',
  `password_hash` VARCHAR(128)    NULL                    COMMENT 'BCrypt；纯 SSO 用户为空',
  `name`          VARCHAR(64)     NOT NULL                COMMENT '姓名',
  `email`         VARCHAR(128)    NOT NULL                COMMENT '邮箱，SSO 匹配键',
  `phone`         VARCHAR(20)     NULL                    COMMENT '手机号（AES 加密）',
  `avatar`        VARCHAR(255)    NULL                    COMMENT '头像地址',
  `sso_subject`   VARCHAR(128)    NULL                    COMMENT 'OIDC sub，SSO 用户唯一',
  `enabled`       TINYINT(1)      NOT NULL DEFAULT 1      COMMENT '1 启用 0 停用',
  `last_login_at` DATETIME(3)     NULL                    COMMENT '最近登录时间',
  `last_login_ip` VARCHAR(45)     NULL                    COMMENT '最近登录 IP',
  `created_at`    DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at`    DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_username` (`username`),
  UNIQUE KEY `uk_user_email` (`email`),
  UNIQUE KEY `uk_user_sso` (`sso_subject`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='平台用户';

-- ---------------------------------------------------------------------------
-- 1.2 角色
-- ---------------------------------------------------------------------------
CREATE TABLE `role` (
  `id`         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `code`       VARCHAR(32)     NOT NULL COMMENT '角色标识：admin/ops/dev/qa/readonly',
  `name`       VARCHAR(64)     NOT NULL COMMENT '角色名称',
  `description` VARCHAR(255)   NULL     COMMENT '说明',
  `builtin`    TINYINT(1)      NOT NULL DEFAULT 1 COMMENT '是否内置角色（内置不可删除）',
  `sort`       INT             NOT NULL DEFAULT 0,
  `created_at` DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_role_code` (`code`)

-- ---------------------------------------------------------------------------
-- 1.3 权限点
-- ---------------------------------------------------------------------------

  `module`      VARCHAR(32)     NOT NULL COMMENT '所属模块：project/build/deploy/...',
  `description` VARCHAR(255)    NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_perm_code` (`code`),
  KEY `idx_perm_module` (`module`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限点';

-- ---------------------------------------------------------------------------
-- 1.4 关联表
-- ---------------------------------------------------------------------------
CREATE TABLE `user_role` (
  `id`         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id`    BIGINT UNSIGNED NOT NULL,
  `role_id`    BIGINT UNSIGNED NOT NULL,
  `created_at` DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_role` (`user_id`, `role_id`),
  KEY `idx_ur_role` (`role_id`)

CREATE TABLE `role_permission` (

  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_role_perm` (`role_id`, `permission_id`)
```

## 2. 项目（project / project_member）

```sql
CREATE TABLE `project` (
  `id`              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `project_key`     VARCHAR(64)     NOT NULL COMMENT '项目标识，全局唯一，如 user-web',
  `name`            VARCHAR(128)    NOT NULL COMMENT '项目名称',
  `type`            VARCHAR(16)     NOT NULL COMMENT '类型：frontend/backend',
  `git_provider`    VARCHAR(16)     NOT NULL DEFAULT 'gitlab' COMMENT 'gitlab/github/gitee',
  `git_url`         VARCHAR(255)    NOT NULL COMMENT 'Git 仓库地址',
  `git_username`    VARCHAR(128)    NULL      COMMENT '拉代码的账号（明文，不是秘密，空=匿名）',
  `git_credential_id` BIGINT UNSIGNED NULL COMMENT '拉代码的密码/令牌，引用 secret_credential.id',
  `default_branch`  VARCHAR(96)     NOT NULL DEFAULT 'master' COMMENT '默认分支',
  `build_method`    VARCHAR(16)     NOT NULL DEFAULT 'dockerfile' COMMENT 'dockerfile/jenkins/script',
  `jenkins_job`     VARCHAR(128)    NULL      COMMENT 'build_method=jenkins 时的 Job 名',
  `dockerfile_path` VARCHAR(255)    NOT NULL DEFAULT 'Dockerfile' COMMENT 'Dockerfile 路径（仅 dockerfile 模式）',
  `build_context`   VARCHAR(255)    NOT NULL DEFAULT '.' COMMENT '构建上下文（仅 dockerfile 模式）',
  `build_script`    TEXT            NULL      COMMENT 'build_method=script 的完整构建脚本（可读可改，默认值由 go:embed 下发）',
  -- build_env：编译环境标识（jdk8 / jdk21 / node22）。空 = 任意在线构建机都可执行。
  -- ⚠️ 它**不是外键、也没有对应的主数据表**：环境是「当前在线构建机的 labels.env 去重聚合」，
  --    不是一个能被人为声明出来的事实。建表会产生「环境在列表里、一台机器都没有」的悬空态。
  --    匹配规则只是 runner.labels.env == project.build_env 的等值比较。
  `build_env`       VARCHAR(64)     NULL      COMMENT '编译环境标识（jdk8/jdk21/...），空=任意在线构建机',
  `registry`        VARCHAR(128)    NOT NULL COMMENT '镜像仓库地址',
  `image_name`      VARCHAR(128)    NOT NULL COMMENT '镜像名称，如 frontend/user-web',
  `tag_pattern`     VARCHAR(128)    NOT NULL DEFAULT 'v{buildNo}' COMMENT 'Tag 规则，支持 {buildNo}(可带内联偏移 {buildNo±N})/{branch}/{commitId}/{timestamp}/{date}',
  `build_params`    JSON            NULL      COMMENT '构建参数 [{key,value,desc,secret}]',
  `timeout_sec`     INT             NOT NULL DEFAULT 1800 COMMENT '构建超时秒数',
  `owner_id`        BIGINT UNSIGNED NOT NULL COMMENT '负责人 user.id',
  `team`            VARCHAR(64)     NULL      COMMENT '所属团队',
  `description`     VARCHAR(512)    NULL      COMMENT '描述',
  `enabled`         TINYINT(1)      NOT NULL DEFAULT 1 COMMENT '启用状态',
  `auto_build`      TINYINT(1)      NOT NULL DEFAULT 0 COMMENT 'Webhook 自动构建',
  `auto_build_branches` JSON        NULL      COMMENT '自动构建分支白名单 ["master","release/*"]',
  `created_by`      BIGINT UNSIGNED NULL,
  `updated_by`      BIGINT UNSIGNED NULL,
  `created_at`      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at`      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  `deleted_at`      DATETIME(3)     NULL COMMENT '软删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_project_key` (`project_key`),
  KEY `idx_project_type_enabled` (`type`, `enabled`),
  KEY `idx_project_owner` (`owner_id`),
  KEY `idx_project_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='CI 项目';

CREATE TABLE `project_member` (
  `id`         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `project_id` BIGINT UNSIGNED NOT NULL,
  `user_id`    BIGINT UNSIGNED NOT NULL,
  `role`       VARCHAR(16)     NOT NULL DEFAULT 'developer' COMMENT 'owner/maintainer/developer/reporter',
  `created_at` DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_pm` (`project_id`, `user_id`),
  KEY `idx_pm_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='项目成员授权';
```

## 3. 构建（build_record / build_log / image_record）

```sql
CREATE TABLE `build_record` (
  `id`            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `build_no`      INT UNSIGNED    NOT NULL COMMENT '项目内自增构建号 #1183',
  `project_id`    BIGINT UNSIGNED NOT NULL,
  `project_key`   VARCHAR(64)     NOT NULL COMMENT '冗余，便于查询与展示',
  `branch`        VARCHAR(96)     NOT NULL COMMENT '构建分支',
  `commit_id`     VARCHAR(40)     NOT NULL COMMENT 'commit sha（短 7 位 + 全量 40）',
  `commit_msg`    VARCHAR(512)    NULL     COMMENT 'commit 说明',
  `trigger_type`  VARCHAR(16)     NOT NULL DEFAULT 'manual' COMMENT 'manual/webhook/schedule/retry',
  `trigger_by`    BIGINT UNSIGNED NULL     COMMENT '触发人 user.id；系统触发为 NULL',
  `trigger_name`  VARCHAR(64)     NULL     COMMENT '触发人姓名（冗余）',
  `params_snapshot` JSON          NULL     COMMENT '本次构建实际使用的参数快照',
  `status`        VARCHAR(16)     NOT NULL DEFAULT 'queued' COMMENT 'queued/running/success/failed/canceled',
  `stage`         VARCHAR(32)     NULL     COMMENT '当前阶段文案',
  `progress`      TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '0-100',
  `duration_sec`  INT UNSIGNED    NULL     COMMENT '耗时秒',
  `runner_id`     VARCHAR(64)     NULL     COMMENT '执行该任务的 Runner 标识；Jenkins 项目写死 jenkins',
  `jenkins_job`     VARCHAR(128)  NULL     COMMENT '由 Jenkins 执行时：Job 的 fullName（文件夹内带路径）',
  `jenkins_build_no` INT UNSIGNED NULL     COMMENT 'Jenkins 侧的构建号（可空：队列项转构建号要等执行器，转不到则一直为空）',
  `jenkins_queue_id` BIGINT UNSIGNED NULL  COMMENT 'Jenkins 队列项 id，用于触发后的补偿（撤销）与状态跟踪',
  `image_record_id` BIGINT UNSIGNED NULL   COMMENT '成功后关联的镜像记录',
  `log_size`      INT UNSIGNED    NOT NULL DEFAULT 0 COMMENT '日志字节数',
  `log_url`       VARCHAR(255)    NULL     COMMENT '超过阈值后归档到对象存储的地址',
  `error_code`    VARCHAR(64)     NULL     COMMENT '失败分类码：DEP_RESOLVE/PUSH_DENIED/OOM/...',
  `error_message` VARCHAR(512)    NULL     COMMENT '失败真因（人类可读原文）。error_code 用于筛选/统计，这一列用于解释；2026-10-10 加（此前真因只进易失的日志流，重启即丢）',
  `ai_diagnosis`  JSON            NULL     COMMENT 'AI 归因 {reason,suggestion,confidence}',
  `idempotency_key` VARCHAR(128)  NULL     COMMENT '幂等键',
  `started_at`    DATETIME(3)     NULL,
  `finished_at`   DATETIME(3)     NULL,
  `created_at`    DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at`    DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_build_no` (`project_id`, `build_no`),
  UNIQUE KEY `uk_build_idem` (`idempotency_key`),
  KEY `idx_build_status_time` (`status`, `created_at`),
  KEY `idx_build_project_time` (`project_id`, `created_at` DESC),
  KEY `idx_build_commit` (`project_key`, `commit_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='构建记录';

-- Jenkins 三个字段只在 build_method=jenkins 的项目上有值，都是"可空"：
--   · jenkins_build_no 可空是**本质的**——Jenkins 接受触发请求时只给队列项，
--     真正的构建号要等执行器空闲才出现；转不到就应留空，不能编一个。
--   · jenkins_queue_id 有值才能在"平台建单失败"时把已经排上的那次构建撤销，
--     否则用户会看到"平台报错，但 Jenkins 上莫名多了一次构建"。
--   · commit_id 在这种记录里**刻意留空**：检出哪个提交由 Jenkins 侧 Job 配置决定，
--     按 GitLab 查一个分支 tip 填进来会得到一个"看起来对、其实不对"的提交号。

-- 日志分片表：Redis Stream 只做实时推送，落库用分片避免单行 TEXT 超长
CREATE TABLE `build_log` (
  `id`         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `build_id`   BIGINT UNSIGNED NOT NULL,
  `seq`        INT UNSIGNED    NOT NULL COMMENT '行序号，SSE Last-Event-ID 对齐',
  `level`      VARCHAR(8)      NOT NULL DEFAULT 'info' COMMENT 'info/warn/error/cmd',
  `content`    VARCHAR(2000)   NOT NULL COMMENT '单行日志（超长截断）',
  `logged_at`  DATETIME(3)     NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_log_seq` (`build_id`, `seq`),
  KEY `idx_log_build` (`build_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='构建日志分片';

CREATE TABLE `image_record` (
  `id`             BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `project_id`     BIGINT UNSIGNED NOT NULL,
  `project_key`    VARCHAR(64)     NOT NULL,
  `registry`       VARCHAR(128)    NOT NULL COMMENT '镜像仓库地址',
  `repo`           VARCHAR(255)    NOT NULL COMMENT '仓库路径 frontend/user-web',
  `tag`            VARCHAR(191)    NOT NULL COMMENT 'Tag',
  `image`          VARCHAR(512)    NOT NULL COMMENT '完整地址 repo:tag（冗余，便于展示）',
  `digest`         VARCHAR(80)     NOT NULL COMMENT 'sha256:...',
  `size_bytes`     BIGINT UNSIGNED NULL     COMMENT '镜像大小',
  `arch`           VARCHAR(32)     NULL     COMMENT 'amd64/arm64/multi',
  `branch`         VARCHAR(96)     NOT NULL,
  `commit_id`      VARCHAR(40)     NOT NULL,
  `build_id`       BIGINT UNSIGNED NOT NULL,
  `build_no`       INT UNSIGNED    NOT NULL,
  `pushed_at`      DATETIME(3)     NOT NULL COMMENT '推送时间',
  `pull_count`     INT UNSIGNED    NOT NULL DEFAULT 0 COMMENT '被拉取次数',
  `deployed_envs`  JSON            NULL     COMMENT '已部署环境 ["test","prod"]，清理前校验用',
  `deleted_at`     DATETIME(3)     NULL     COMMENT '镜像已从 Harbor 清理',
  `created_at`     DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_image` (`registry`, `repo`, `tag`),
  KEY `idx_image_project_time` (`project_id`, `pushed_at` DESC),
  KEY `idx_image_build` (`build_id`),
  KEY `idx_image_commit` (`project_key`, `commit_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='镜像版本记录';
```

## 7. Redis Key 设计

| Key | 类型 | TTL | 用途 |
| --- | --- | --- | --- |
| `yn:session:{token}` | String(JSON) | 2h | 登录会话（与 JWT 双校验，支持强制下线） |
| `yn:user:perm:{userId}` | Set | 10m | 用户权限点缓存，角色变更时主动清除 |
| `yn:build:queue` | List / BullMQ | — | 待执行构建任务 |
| `yn:build:{id}:log` | Stream | 24h | 构建日志实时流（SSE 消费） |
| `yn:build:{id}:done` | String | 1h | 任务结束标记（含终态与摘要 JSON） |
| `yn:build:{id}:cancel` | String | 1h | 取消标记，Runner 轮询到即 SIGTERM |
| `yn:deploy:queue` | List / BullMQ | — | 待执行部署任务 |
| `yn:lock:deploy:{env}:{svc}` | String(NX) | 30m | 部署互斥锁（同服务串行） |
| `yn:ratelimit:build:{userId}` | String(incr) | 5m | 构建触发限流 |
| `yn:env:{envKey}:status` | Hash | 60s | 集群健康状态缓存，避免频繁打 K8s API |
| `yn:webhook:dedup:{project}:{commit}` | String(NX) | 10m | Webhook 去重，防重复构建 |

## 8. 关键查询与索引验证

| 场景 | SQL 形态 | 命中索引 |
| --- | --- | --- |
| 项目列表按类型+状态筛选 | `WHERE type=? AND enabled=1 AND deleted_at IS NULL ORDER BY updated_at DESC` | `idx_project_type_enabled` |
| 项目详情带上一次构建 | `WHERE project_id=? ORDER BY created_at DESC LIMIT 1` | `idx_build_project_time` |
| 构建记录按状态筛选 | `WHERE status=? ORDER BY created_at DESC` | `idx_build_status_time` |
| 环境内异常服务 | `WHERE env_key=? AND status<>'running'` | `idx_svc_env_status` |
| 服务部署历史 | `WHERE service_id=? ORDER BY created_at DESC LIMIT 20` | `idx_deploy_service` |
| 镜像是否被环境使用（清理前校验） | 读 `image_record.deployed_envs` JSON + `service_instance.current_image_id` | `idx_svc_project` |
| 审计按用户+时间 | `WHERE user_id=? AND created_at BETWEEN ? AND ?` | `idx_audit_user_time` |
| 重复提交构建 | `WHERE idempotency_key=?` | `uk_build_idem` |

> **注意 `image_record.deployed_envs` 是冗余字段**：以 `service_instance.current_image_id` 为准，
> 每次部署成功事务内同步更新该 JSON 字段（读多写少，用冗余换查询性能）。
