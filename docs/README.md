## 待拍板的问题（详见 `06-MVP排期建议.md` §2.3）

1. **AI 工具要不要按环境收敛权限**？现状：有 `ai:query` 的用户可通过工具读到任意环境
   （**含 prod**）的集群实时值。按环境 / 按角色 / 维持现状。
2. **是否自建构建 Runner**？—— 它决定"构建加速"这条线能不能开（一期走的是 Jenkins 复用）。
3. **`team` 要不要做团队主数据**？—— 它决定二期是否含用户 / 组织治理。
4. **二期先做哪几项**？清单见 `06-MVP排期建议.md` §2.1。

已在实现中定下来的（不必再讨论）：

- 后端**技术栈**：Go 1.26 单栈（Gin + GORM），不是 Spring Boot / NestJS；
- **日志通道**：SSE（不是 WebSocket）；
- **构建执行**：复用已有 Jenkins，不自建 Runner；
- **集群写入**：统一走 AppRelease CR（直改 Deployment 会被 operator 秒拉回）；
- **部署失败不回滚**（2026-10-08 拍板，理由见 `06-MVP排期建议.md` §5）。
